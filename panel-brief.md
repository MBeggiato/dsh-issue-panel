Mode: Operate. Local extension of the established Harness interface, not a new visual identity. User approved master-detail composition and inherited theme. No standalone mock or replacement server.

## Direction contract
THESIS: Scan repository work and carry a complete issue snapshot into the draft without losing context or leaving Harness.
OWN-WORLD: Inherit Harness system typography, alias theme tokens, compact controls and quiet single-line separators. Labels remain readable text rather than arbitrary GitHub background colors.
STORY: Recognize repository and authentication, scan updated open issues, inspect description and discussion, then stage context for review.
FIRST VIEWPORT: Compact header with repository and refresh; filters above a left issue list; wider right detail pane. On narrow widths detail follows list with clear return navigation. Authentication setup is inline, not a modal.
FORM: User-confirmed master-detail local extension; no concept seed required for this precisely specified addition.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
